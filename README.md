## 📖 About

LosslessCut is a lightweight, open source video and audio editor built for one job: cutting media files without re-encoding. It relies on FFmpeg under the hood to slice at keyframes, keeping the original streams intact. The app is maintained by an independent developer and ships with batch cut workflows, segment export, audio track selection, subtitle handling and simple format conversion helpers. Recent builds refreshed the FFmpeg backend and improved segment markers for smoother multi cut sessions.

If you came looking for a LosslessCut download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The app runs locally, handles large files quickly and does not require cloud uploads or account sign ins.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes immediately | Reboot Windows and run the setup file again from a local folder. |
| App opens but shows a blank window | Update your graphics driver and restart LosslessCut. |
| Cut exports take a long time | Disable hardware acceleration in settings and retry the segment. |
| Audio out of sync after a cut | Cut exactly on a keyframe, or enable the keyframe snapping option. |
| Cannot open an MKV or MOV file | Confirm the container is supported, then remux it to MP4 first. |
| Windows blocks the app after an update | Right click the shortcut, choose Properties, and unblock it. |
